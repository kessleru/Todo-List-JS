Uma aplicação minimalista de lista de tarefas (Todo List) desenvolvida com **JavaScript Vanilla**, focando em uma interface limpa e funcionalidades essenciais para gerenciamento de tarefas diárias.

## ✨ Funcionalidades

### 🎯 Gerenciamento de Tarefas

- **Adicionar Tarefas**: Interface intuitiva para criação rápida de novas tarefas
- **Marcar como Completa**: Sistema de checkbox para rastrear tarefas concluídas
- **Excluir Tarefas**: Remoção individual de tarefas com botão de exclusão
- **Limpar Completas**: Botão para remover todas as tarefas concluídas de uma vez
- **Tempo Decorrido**: Exibe há quantos dias a tarefa foi criada (ex: "3 days ago")

### 🔍 Filtros Inteligentes

- **Todas**: Visualização completa de todas as tarefas
- **Ativas**: Exibe apenas tarefas pendentes
- **Completas**: Mostra apenas tarefas já concluídas

### 🎨 Temas Dinâmicos

O aplicativo muda automaticamente seu tema visual baseado no horário do dia:

- **Manhã (6h - 13h)**: Tema azul claro (#3BAFE8)
- **Tarde (13h - 18h)**: Tema laranja (#FF8C42)
- **Noite (18h - 6h)**: Tema roxo (#8B5CF6)

### 💾 Persistência de Dados

- Utiliza **LocalStorage** para salvar tarefas localmente
- Dados persistem entre sessões do navegador
- Carregamento automático ao abrir a aplicação

### 🎭 Tela de Boas-Vindas

- Mensagem personalizada baseada no horário (Bom Dia/Boa Tarde/Boa Noite)
- Animações suaves de entrada
- Transição elegante para a aplicação principal

## 🚀 Tecnologias Utilizadas

### Core

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilização moderna com variáveis CSS e animações
- **JavaScript (ES6+)**: Lógica da aplicação sem frameworks

### Bibliotecas Externas

- **Font Awesome 7.0.1**: Ícones para interface
- **Google Fonts**:
  - IBM Plex Sans (corpo do texto)
  - Fira Sans (tarefas)

### APIs e Recursos

- **LocalStorage API**: Persistência de dados no navegador
- **Date API**: Manipulação de datas e horários
- **DOM API**: Manipulação dinâmica de elementos
